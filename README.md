# SÉRA — Beauty Landing Page

美容・コスメのLPデザイン案件を想定した自主制作。架空のスキンケアブランドです。

## Design
ローズ×ボルドーの配色、和文の明朝体と欧文セリフ体、余白と商品ビジュアルで世界観を表現。ストーリー→特徴→使い方→商品紹介→FAQの順に構成。

## Scope
コンセプト・構成・コピー・商品画像のAI生成・HTML/CSS/JavaScript実装。

## Run
`dist/index.html` を開くか、`python3 -m http.server 8000 --directory dist` を実行。依存パッケージ不要。

## GitHub Pages
リポジトリへこのプロジェクトをアップロード後、Settings → Pages → Source: GitHub Actions を選びます。同梱の `.github/workflows/pages.yml` が `dist` を公開します。GitHubの設定と利用条件により、有効化や追加操作が必要な場合があります。

## Important
架空商品であり、販売・予約・個人情報の収集は行いません。実績数値、レビュー、効果試験等を創作していません。商品画像はAI生成、抽象ビジュアルはCSS制作です。商品・使用感の説明はコンセプトです。商用実績ではなく自主制作として掲載してください。

## Editing
`dist/index.html`: 文言・構成 / `dist/style.css`: デザイン / `dist/script.js`: ダイアログ / `dist/assets/hero.jpg`: 商品画像。
